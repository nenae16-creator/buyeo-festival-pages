# 제72회 백제문화제 안내 데모

[공개 시연 페이지](https://nenae16-creator.github.io/buyeo-festival-pages/) · 이전 버전: [/v1/](https://nenae16-creator.github.io/buyeo-festival-pages/v1/)

제72회 백제문화제의 공개 자료로 만든 **비공식 영업 시연용 앱**입니다. 행사는 종료했으며 공식 서비스가 아닙니다.

새 축제 엔진(festival-engine, React·카카오맵)으로 만든 빌드 결과물입니다. 축제 내용은 `festival.json` 한 파일에서 나옵니다. 사진 홈 화면, 바로가기, 추천 코스 3종(날짜별 공식 일정), 날짜별 프로그램, 내 일정 저장·캘린더(ICS) 내보내기, 카카오맵 행사장 지도(위성/일반, 분류별 보기), 셔틀 노선·주차 구역·공식 공지·FAQ를 제공합니다.

- 일정·셔틀·주차·공지는 공식 누리집 확인 자료입니다(앱의 「자료 출처·사진 저작권」 화면에 원문 링크). 공개되지 않은 값은 지어내지 않고 "미공개"로 둡니다.
- 사진: 위키미디어 공용(국가유산청 공공누리 제1유형·CC BY-SA) — 저작자·원본 링크는 앱 안에 표시합니다.
- 지도: 카카오맵(JavaScript 키, 도메인 등록), 키 인증 실패 시 OpenStreetMap(ODbL)·OpenFreeMap으로 대체.
